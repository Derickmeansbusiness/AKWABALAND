# AKWABA-LAND UAE — Creative Direction

Working tagline: African Heritage · Global Horizons
Visual language: Contemporary African Royal Minimalism

## What we are making

Not a website about the project. The unveiling of it. One scroll, ten acts, the architecture doing the talking. Someone in a family office opens the link and, without reading a paragraph, understands this is a serious piece of development.

## The hierarchy, in order

Image → space → typography → light → motion → rhythm → scale → interface.

If a UI element competes with the picture behind it, the element loses.

## Benchmarks (for discipline, never for copying)

EMAAR launch films for restraint in camera movement. Diriyah for how to hold a dark frame with one line of serif. NEOM for sequencing statements. Louvre Abu Dhabi's identity for how little gold you actually need. Architectural monographs for type.

## Palette

| token | hex | job |
|---|---|---|
| obsidian | `#090908` | the base of everything; the opening and the map |
| warm black | `#11100D` | surfaces lifted off obsidian |
| ivory | `#F2EEE5` | primary text on dark |
| stone | `#D8D0C2` | secondary text, hairlines |
| antique gold | `#B79A58` | accent only: a marker, a rule, a hover, a country on the map |
| bronze | `#72502C` | the sculpture, the map's resting state |
| forest | `#183328` | rare; a tonal shift in Living Traditions |
| earth | `#9B8167` | captions, muted labels |
| soft white | `#FAF8F3` | reserved for one or two statements |

Gold rule: if more than one gold element is on screen at once, one of them is wrong.

## Typography

Display: Cormorant Garamond (self-hosted via Fontsource) — light and regular weights only, generous optical size, tight-but-breathing letter-spacing, never bold.
Text and labels: Geist Sans — 300/400, uppercase labels tracked at 0.18–0.28em, 10–12px.

Display scale is fluid, capped. A statement should feel placed, not inflated. Max line length 28ch for display, 62ch for prose.

## Space

Every act can breathe. Several screens carry under twenty words. Image alone + one statement + a progress mark is a complete composition.

## Motion grammar

Allowed: camera push, pull, depth reveal, mask reveal, image expansion, horizontal tracking, controlled text clipping, lens-like transitions, crossfade through black, light changes, material reveal, scroll-linked scrubbing where it earns it.

Forbidden: bounce, elastic, rapid scale, flips, rotating UI, bubbles, particle bursts, heavy blur, overdone parallax, cursor theatrics.

Easing: `power2.out` for UI, `power3.out` for statements, `expo.out` for reveals, and one custom curve `cubic-bezier(0.16, 1, 0.3, 1)` for cinematic scenes.

Scrub is for camera; thresholds are for text. Not everything should move with the finger.

## Copy posture

Diplomatic, concise, institutional, warm where it counts. "Proposed", "envisioned", "conceptual", "subject to feasibility". Never a claim of endorsement, land, capital, partners, attendance or returns. No "revolutionary", no "game-changing".

## Three questions before any element ships

1. Would this be at home in a printed architectural monograph?
2. Does it make the image behind it better or worse?
3. Would it embarrass us in a royal family office?
